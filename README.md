# 🛡️ Azure SOC + Honeynet Lab

## 📄 Overview

In this project, I build a mini honeynet in Azure and ingest logs from various resources into a Log Analytics Workspace, which is then used by Microsoft Sentinel to build attack maps, trigger alerts, and create incidents. I measured some security metrics in the insecure environment for 24 hours, applied security controls to harden the environment, measured metrics for another 24 hours, and then shared the results

---

## ⚙️ Lab Architecture

### Components:
- **Virtual Network (VNet)**
- **Network Security Group (NSG)**  
- **Virtual Machines (VMs):**
  - **Windows Honeypot VM**
  - **Linux Honeypot VM**
  - **Windows Attacker VM**
- **Azure Monitor and Log Analytics Workspace**
- **Azure Key Vault**
- **Azure Storage Account**
- **Microsoft Sentinel**



---

## 📊 Metrics Collected

| Metric Source | Description |
|:---|:---|
| **SecurityEvent** | Windows Event Logs (logon attempts, critical events) |
| **Syslog** | Linux Event Logs (system authentication, errors) |
| **SecurityAlert** | Alerts triggered in Log Analytics |
| **SecurityIncident** | Incidents generated by Microsoft Sentinel |
| **AzureNetworkAnalytics_CL** | Malicious network flows allowed into the honeynet |

## 🛠️ Data Collection Setup

- **Windows VMs**:  
  - Installed **Azure Monitor Windows Agent**.
  - Applied **Data Collection Rule (DCR)** with custom **XPath queries** to filter:
    - Critical Application events
    - Security login events
    - Defender malware detection
    - Firewall blocked traffic events

- **Linux VM**:
  - Configured to forward **Syslog** to **Log Analytics**.

- **Resource Diagnostic Logs**:
  - Configured **Diagnostic Settings** on Azure services (e.g., Key Vault, Storage Account) to send their **AuditLogs**, **Resource Logs**, and **Metrics** to **Log Analytics Workspace**.
  - Example services configured:
    - **Azure Key Vault** (Access logs, audit logs)
    - **Azure Storage Account** (read/write/delete operations)
    - *(extend to other services if needed)*

- **Microsoft Sentinel**:  
  - Connected to Log Analytics.
  - Alert rules configured for key security events.
